# cursor

The `cursor` workload is maintained in Docker Hardened Images.
Its definition is in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/cursor).

```console
sbx run dhi.io/cursor:latest /path/to/workspace
```

Use the DHI reference for new sandboxes. This repository no longer builds
or updates `docker.io/sbx/cursor`. Previously published tags are not
removed by this change.
