# droid-mixin

The `droid-mixin` agent mixin is maintained in Docker Hardened Images.
Its definition is in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/droid-mixin).

```console
sbx run --kit dhi.io/droid-mixin:latest dhi.io/shell:latest /path/to/workspace
```

Use the DHI reference for new sandboxes. This repository no longer builds
or updates `docker.io/sbx/droid-mixin`. Previously published tags are not
removed by this change.
