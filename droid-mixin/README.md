# droid-mixin

The `droid-mixin` agent mixin is maintained in Docker Hardened Images.
Its agent image is documented in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/droid).

```console
sbx run --kit docker.io/sbx/droid-mixin:latest docker.io/sbx/shell:latest /path/to/workspace
```

DHI builds and publishes `docker.io/sbx/droid-mixin`. This repository no longer
builds or updates the kit. Previously published tags remain available.
