# kiro

The `kiro` workload is maintained in Docker Hardened Images.
Its definition is in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/kiro).

```console
sbx run dhi.io/kiro:latest /path/to/workspace
```

Use the DHI reference for new sandboxes. This repository no longer builds
or updates `docker.io/sbx/kiro`. Previously published tags are not
removed by this change.
