# github-cli

GitHub CLI with proxy-managed authentication. The `github-cli` Kit is maintained in
[Docker Hardened Images](https://github.com/docker-hardened-images/catalog/tree/main/image).
The [Docker Hub page](https://hub.docker.com/r/sbx/github-cli) documents
its prerequisites, supported workloads, and create-time arguments.

```console
sbx run sbx/shell --kit sbx/github-cli /path/to/workspace
```

The kit is named `github-cli`; the installed command remains `gh`.
Use this reference in place of older `gh` kit references.

This directory is a documentation pointer and has no local descriptor
or publisher. Use the published DHI Kit for new sandboxes.
