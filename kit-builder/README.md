# kit-builder

The `kit-builder` workload is maintained in Docker Hardened Images.
Its definition is in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/kit-builder).

```console
sbx run dhi.io/kit-builder:latest /path/to/workspace
```

Use the DHI reference for new sandboxes. This repository no longer builds
or updates `docker.io/sbx/kit-builder`. Previously published tags are not
removed by this change.
