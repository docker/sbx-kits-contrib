# droid

The `droid` workload is built and published by Docker Hardened Images.
See the [Docker Hub page](https://hub.docker.com/r/sbx/droid) for usage and tags,
and the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image)
for public image definitions.

```console
sbx run docker.io/sbx/droid:latest /path/to/workspace
```

DHI builds and publishes `docker.io/sbx/droid`. This repository no longer
builds or updates the kit. Previously published tags remain available.
