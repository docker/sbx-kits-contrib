# copilot

The `copilot` workload is maintained in Docker Hardened Images.
Its agent image is documented in the [DHI catalog](https://github.com/docker-hardened-images/catalog/tree/main/image/copilot).

```console
sbx run docker.io/sbx/copilot:latest /path/to/workspace
```

DHI builds and publishes `docker.io/sbx/copilot`. This repository no longer
builds or updates the kit. Previously published tags remain available.
