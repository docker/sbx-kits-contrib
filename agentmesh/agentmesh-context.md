## Agent Mesh

An Agent Mesh node runs in this sandbox, registered with you as the MCP server
`agentmesh`. Follow that server's instructions to find and use the mesh's
services. The mesh's policy decides which calls are allowed, so a refused call
is a policy decision, not an error to work around. Node logs:
`~/.agentmesh/agentmesh-node.log` and `~/.agentmesh/hooks.log`.
